An approval multisig realm, ported from the classic Solidity idea. A fixed set
of owners is configured once with a required approval threshold. Any owner can
create a proposal, owners approve it, and when the number of distinct approvals
reaches the threshold the proposal is automatically marked `Executed`. This
realm tracks approvals only — it does not custody or move funds.

**Realm path:** `gno.land/r/REPLACE_ADDR/multisig`

## Example calls

```sh
# Initialize once: 3 owners, need 2 approvals to execute.
gnokey maketx call -pkgpath "gno.land/r/REPLACE_ADDR/multisig" \
  -func Setup -args "g1addr1,g1addr2,g1addr3" -args 2 ...

# An owner creates a proposal (returns its id, e.g. 0).
gnokey maketx call -pkgpath "gno.land/r/REPLACE_ADDR/multisig" \
  -func Propose -args "send funds to treasury" ...

# Owners approve; the 2nd distinct approval flips it to Executed.
gnokey maketx call -pkgpath "gno.land/r/REPLACE_ADDR/multisig" \
  -func Approve -args 0 ...
```

Render the realm (owners, threshold, proposals with approval counts + state) by
browsing to its path on gno.land.
