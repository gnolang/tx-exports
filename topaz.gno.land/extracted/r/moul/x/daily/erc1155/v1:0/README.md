# erc1155

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Solidity→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

An idiomatic gno.land port of the Solidity **ERC-1155** multi-token standard.
One realm manages many distinct token ids, each with independent fungible
balances tracked in an `avl.Tree` keyed by `(owner, id)`, plus a per-id total
supply. It keeps the core ERC-1155 ideas — minting, single transfers, balance
and supply queries, and events — while dropping the Solidity-specific machinery
(operator approvals, safe-transfer callbacks) that has no analog on gno.land.

## Transactions

- `Mint(cur realm, to address, id int, amount uint64)` — mint `amount` of token
  `id` to `to`; increases that id's total supply.
- `TransferSingle(cur realm, to address, id int, amount uint64)` — move `amount`
  of token `id` from the caller to `to`.

## Read-only

- `BalanceOf(owner address, id int) uint64` — balance of one owner for one id.
- `TotalSupply(id int) uint64` — total minted for a given id.
- `Render(path string)` — Markdown balances table (owner · id · amount) and a
  per-id supply table.

## Example

```
Mint(cur, g1owner..., 1, 100)      // 100 units of token #1 to g1owner
Mint(cur, g1owner..., 2, 5)        // 5 units of token #2
TransferSingle(cur, g1other..., 1, 40)  // caller sends 40 of token #1
BalanceOf(g1owner..., 1)           // -> 60
TotalSupply(1)                     // -> 100
```
