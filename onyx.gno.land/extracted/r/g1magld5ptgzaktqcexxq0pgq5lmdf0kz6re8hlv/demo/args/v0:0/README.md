# `gno.land/r/moul/demo/args`

Step 2 of the `r/moul/demo` walkthrough: passing arguments to an exported
function.

```go
func Hello(name string) string { return "Hello " + name + "!" }
```

Arguments arrive from the transaction as strings and are decoded into the
declared parameter types. There is no state here: the realm reads its input and
returns, so two identical calls return the same thing.

```bash
gnokey maketx call -pkgpath gno.land/r/moul/demo/args \
  -func Hello -args People -gas-fee 20000ugnot -gas-wanted 2000000 -broadcast moul
```

Previous: [`hello`](../hello). Next: [`data`](../data) adds state that survives
the call.
