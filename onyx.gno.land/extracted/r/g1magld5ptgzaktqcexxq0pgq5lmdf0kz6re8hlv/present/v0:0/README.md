# `gno.land/r/moul/present`

An on-chain slide deck: store a Markdown presentation, then read it back either
as one page or one slide at a time.

```go
func Set(cur realm, slug, title, event, author, date, content string) string
func Delete(cur realm, slug string) string
```

Both are owner-gated through [`p/nt/ownable`](https://github.com/gnolang/gno/tree/master/examples/gno.land/p/nt/ownable).
`Set` is an upsert: same slug, new content.

## Routes

| path | view |
| --- | --- |
| `""` | index of every presentation |
| `<slug>` | the whole deck on one page |
| `<slug>/slides` | slide 1 |
| `<slug>/slides?page=N` | slide N |

Slides are split on `##` headings, so the deck is authored as ordinary Markdown
and needs no slide markup. Path parsing goes through
[`p/moul/realmpath`](../../../p/moul/realmpath), so the navigation links are
built from the request rather than hardcoded.

Presentations are indexed twice, by `seqid` and by slug, which is what lets the
index be listed in insertion order while URLs stay readable.

A `demo` presentation is seeded at deploy time by `present_init.gno`.
