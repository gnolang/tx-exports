# `gno.land/r/moul/x/daily/geohashdemo/v0`

**A gnoweb demo of [`p/moul/x/daily/geohash`](https://github.com/moul/gno-contracts/tree/main/p/moul/x/daily/geohash)**,
the base32 geohash library. Three read-only pages, no state, no caller input.

| path | shows |
|---|---|
| `/` | one point encoded at every length from 1 to 11, so the prefix property is visible |
| `/cell` | the box `ezs42` actually names, its bounds and its size in degrees |
| `/neighbors` | the eight cells around it, and the wrap at the antimeridian |

It contains no geohash logic of its own: every string on the page comes from
the library. `Render` takes nothing from a caller and reads no clock, height or
balance, so all three pages are pinned exactly by `ExampleRender` tests.

The page worth reading is `/neighbors`. The cell east of `z` is `b`, because
longitude wraps, while `z` has no northern neighbour at all and `Neighbors`
returns five cells rather than eight. That asymmetry is the part of geohash
adjacency people get wrong.
