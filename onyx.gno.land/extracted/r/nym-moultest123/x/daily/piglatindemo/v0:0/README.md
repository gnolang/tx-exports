# `gno.land/r/nym-moultest123/x/daily/piglatindemo/v0`

Interactive gnoweb **demo of the [`p/moul/x/daily/piglatin`](https://github.com/moul/gno-contracts/tree/main/p/nym-moultest123/x/daily/piglatin)
Pig Latin library** — it renders the rules, a gallery of worked examples, and a
live sentence translator. It has no translation logic of its own.

Append a sentence to the path to translate it, e.g.
[`/r/nym-moultest123/x/daily/piglatindemo/v0:/The quick brown fox`](https://gno.land/r/nym-moultest123/x/daily/piglatindemo/v0:/The%20quick%20brown%20fox).
