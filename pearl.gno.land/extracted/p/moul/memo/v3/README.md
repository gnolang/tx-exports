# `gno.land/p/moul/memo/v3`

A simple memoization utility to cache function results, **backed by a B+ tree**
(`gno.land/p/nt/bptree`).

The B+ tree successor to [`p/moul/memo/v2`](https://github.com/moul/gno-contracts/tree/main/p/moul/memo/v2)
(AVL-backed). **v3 because the backing data structure — and thus the on-chain
storage layout — changed** (a compatibility change ⇒ new version). A B+ tree
packs many entries per persisted node, so it costs materially less storage and
gas per cached entry — prefer v3 for persisted realm state. The exported API is
identical to v2.

```go
import "gno.land/p/moul/memo/v3"

m := memo.New()

// Cache expensive computation; subsequent calls with the same key
// return the cached result without re-running the function.
result := m.Memoize("key", func() any {
	return "computed-value"
})

m.Invalidate("key") // drop one entry
m.Clear()           // drop all entries
m.Size()            // number of cached entries
```

> ⚠️ **Gno usage:** storage updates only persist during transactions. Memoizing
> during queries/render will not persist and only wastes resources — use this in
> transaction-driven contexts.

**Differences from v2:** the API is the same, but because the B+ tree mutates in
place (the AVL backing was copy-on-write), do not Invalidate/add entries from
inside a callback iterating the same Memoizer, and do not copy a non-zero
`Memoizer` by value.
