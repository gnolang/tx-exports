# `gno.land/p/moul/svg/v2`

Minimalist, extensible SVG generation library for Gno.

This is the B+ tree successor to [`gno.land/p/moul/svg/v1`](../v1). The canvas
style map is now backed by [`gno.land/p/nt/bptree/v0`](https://gno.land/p/nt/bptree/v0)
instead of an AVL tree. The version bump reflects a storage-layout change (the
on-chain representation of the styles differs); the exported API is otherwise
identical to v1.

Prefer v2 when the canvas is part of persisted realm state: a B+ tree packs many
entries per persisted node, so styles cost less storage and inserts spend less
gas.

**Compatibility caveats** (from the in-place-mutating B+ tree backing):

- do not call `AddStyle` from inside a `Canvas.String`/`Render` iteration;
- do not copy a non-zero `Canvas` by value once styles have been added — the
  copies would share live tree nodes (v1's AVL copies were independent).
