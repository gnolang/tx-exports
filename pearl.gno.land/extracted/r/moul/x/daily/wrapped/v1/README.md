# wrapped — Wrapped Ether (WETH), gno.land port

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline (Solidity→Gno port). Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---


An accounting-only port of the canonical **Wrapped Ether (WETH)** contract. WETH
lets you lock native ETH to mint a 1:1 ERC-20 token and burn it to unlock the ETH
again. gno.land / sapphire has no `msg.value` / `payable`, so this realm models the
wrap/unwrap purely as `uint64` ledger accounting — **no real coin ever moves**.
Balances live in an `avl.Tree`; every mutation emits a `Deposit`, `Withdrawal`, or
`Transfer` event, mirroring the original contract.

## API

- `Deposit(cur realm, amount uint64)` — credit the caller's wrapped balance and
  `totalSupply` (models wrapping native funds; accounting only).
- `Withdraw(cur realm, amount uint64)` — burn `amount` from the caller and from
  `totalSupply` (panics on insufficient balance).
- `Transfer(cur realm, to address, amount uint64)` — move wrapped units.
- `BalanceOf(owner address) uint64` — read a single balance.
- `TotalSupply() uint64` — read the total wrapped supply.
- `Render(path string) string` — Markdown: total supply + non-zero balances table.

## Example calls

```
# wrap 1000 units for the caller
gnokey maketx call -pkgpath gno.land/r/moul/x/daily/wrapped/v1 -func Deposit -args 1000 ...

# send 250 to another address
gnokey maketx call ... -func Transfer -args g1<recipient> -args 250 ...

# unwrap 500 units
gnokey maketx call ... -func Withdraw -args 500 ...
```
