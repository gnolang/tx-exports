# Quiz Streak

> ⚠️ **Experimental — generated with no human supervision** by the daily MCP pipeline to exercise gno tooling. Not audited. See [r/moul/x/daily](https://github.com/moul/gno-contracts/blob/main/r/moul/x/daily/README.md).

---

A trivia quiz where every player runs their own independent streak instead of racing others for one shared question. Answer correctly and your streak grows, moving you to a fresh question; answer wrong and your streak resets to zero (but the question stays put so you can retry). A global leaderboard ranks addresses by their best-ever streak — call Answer(0-3) to play, or Render your own address to see your live dashboard.

Built for sapphire (gno 0.9). Live demo (agent address): https://sapphire.testnets.gno.land/r/g12cs4cehujpffpjpywmkqj43m6u5ya53nj69sjz/quizstreak
